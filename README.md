# Carom

Carom is a top-down paddle duel about reading angles, adding spin, and banking the ball around a pair of fixed obstacles. Play against the house in Solo or challenge another player locally in Versus.

## Install

```sh
npm ci
```

## Run in development

```sh
npm run dev
```

Open the local URL Vite prints in the terminal.

## Production build

```sh
npm run build
```

Vite writes a self-contained static site to `dist/`. Serve that directory from the root of any static web server.

## Controls

- Player one: **W / S**
- Player two in Versus: **↑ / ↓**
- Menu: **↑ / ↓**, **Enter** or **Space**
- Pause or resume: **P** or **Esc**
- Return/back: **Esc**
- Toggle sound: **M**

On touchscreens, use the engine's on-screen vertical controls and menu buttons. First to 11 points wins by two. Moving a paddle as it meets the ball adds spin to its flight; use the gold obstacles for bank shots.
